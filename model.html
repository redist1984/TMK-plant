    Расстановка — по координатам генплана UZLS-3147-4T100-01 Rev.E (2026.08.05), размеры аппаратов — по перечням оборудования. Конвертер, печь, теплообменники газ–газ, воздухоподогреватель, башни, циркуляционный бак, плавильные и фильтровальные баки, скруббер и резервуары построены по листам общего вида НСО (3147-5H111…5H123). Расстановка оборудования отделений 111, 112 и 113 — по планам расположения 3147-5G111-07/08, 3147-5G112-06/07, 3147-5G113-05; эстакады — два яруса EL 5,600 и 7,100 по 3147-5G116 (эстакада отделения 112 по осям B101/B102 — с верхним ярусом 8,540 под воздуховод PA-11201). Габариты, отмеченные в карточке как «условные», приблизительные. Трубопроводы показывают направление потоков по технологическим схемам, а не реальную трассировку; исключение — газоходы и воздуховоды отделения 112, проложенные по плану и разрезам 3147-5G112-08…17 (Rev.0, 2026.5.6) с подключением к штуцерам аппаратов. Здания — по архитектурным чертежам 5J101…5J142 (отметки, кровли, перекрытия, краны), отделка фасадов — по архитектурному рендеру (SULFAT, 2026); внешние сети — по проектам ГСН 12/792, НВ (В0) и КЛ-10 кВ /2026-07-ЭС; внутреннее устройство аппаратов на разрезах схематичное. Нормы режима — по временному технологическому регламенту, табл. 8.1.
